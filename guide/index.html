Reservation Only

ご予約について

混雑を避け、ゆったり過ごしていただくため完全予約制です。当日21:00まで受け付けます。予約のない方は、21:00以降のご入店をお断りする場合があります。

受付できる連絡先

会員専用ダイヤル／支配人・店長の携帯電話／メールアドレス／LINE（ご存じの方のみ）

受付できない連絡先

本社代表電話番号／店舗の公式LINE

はじめての方：火・水・土のオープンダイニング、またはイベントからどうぞ。

How to Enter

入店方法

  1. 01メインエントランスへ出入口はすべてオートロックです
  2. 02予約番号を入力して開錠会員紹介カードの方。会員は所定の方法で開錠
  3. 03クロークでチェックインLP盤「ニューヨーク52番街」がお出迎え

オープンダイニング・イベント開催日はオートロックを解除しています。その他のご用はエントランスのインターホンへ。

Dress Code

ドレスコード

男性のお客様のみスマートカジュアルをお願いしています。迷ったら「ゴルフ場に入場するときの服装」を目安にしてください。

ネクタイは不要。6〜9月はジャケット着用免除。貸出用ジャケットはありません。女性の規定はありません。ライブ・イベント時は特に記載がなければドレスコードなし。

Admission

入場制限

  • 建物敷地内全面禁煙（電子タバコも不可）
  • タトゥー・入れ墨の露出不可
  • 1グループ4名様まで（5名以上はお断りする場合あり）
  • ビジター会員はレギュラー会員以上の同伴が必要
  • 高校生・18歳未満は入場不可（ライブ・イベント時は記載がなければ可）
  • 「反社会的勢力排除に関する誓約書」へのご署名
